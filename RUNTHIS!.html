03 - toolkit

Built for a locked-down machine.

A few practical controls for a shared or restricted machine.

Tab disguise

Choose a destination in Settings. Cloak opens that website in a new tab, so you can leave the current view quickly.

Panic key

Use the keyboard shortcut to switch away quickly. The current page may need to reload when you return.

Cloaked window

Open the current page directly in an about:blank popup. This bypasses the server route, and some sites refuse framing.

Known limits

Server mode is for public documents. Script-heavy sites, logins, and forms are not supported.
